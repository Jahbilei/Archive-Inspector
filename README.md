# Archive Inspector

Android app for inspecting, decrypting, and re-encrypting Unity ES3 save
archives.

## Requirements

- Android 8.0 (API 26) or newer
- Optional: [Shizuku](https://github.com/thedjchi/Shizuku/releases) is
  needed only to access folders under `/Android/data` and
  `/Android/obb/`. All other features work without it.

## Install

1. Download the latest `.apk` from the [Releases](../../releases) page.
2. Open the file on your device and confirm installation (you may need
   to allow "Install from unknown sources" for your browser or file
   manager).
3. Launch Archive Inspector.

## Updates

New versions are posted as GitHub Releases on this repo. To update,
download the newest `.apk` and install it over the existing app — your
data is preserved.

If you use [Obtainium](https://github.com/ImranR98/Obtainium), add this
repo's URL as a source. Obtainium will detect new releases and offer to
update automatically.
